2. What Lockie does

Lockie helps you limit distracting apps: it blocks the apps you choose using Apple's Screen Time features and unlocks them for a set time after you solve a puzzle. You can pause, change or remove locks in the app, and revoke Screen Time access in iOS Settings, at any time. Emergency unlocks (a few each week, shown in the app) open an app briefly without a puzzle. Strict mode is something you choose: while it\'s on, weakening your locks first needs three hard puzzles. Lockie is a self-control tool. It isn't a parental-control or security product, and it can't guarantee that every app is blocked at all times. iOS controls Screen Time behaviour.
