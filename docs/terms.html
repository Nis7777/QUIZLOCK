2. What QuizLock does

QuizLock helps you limit distracting apps: it blocks the apps you choose using Apple's Screen Time features and unlocks them for a set time after you solve a puzzle. You can pause, change or remove locks in the app, and revoke Screen Time access in iOS Settings, at any time. QuizLock is a self-control tool. It isn't a parental-control or security product, and it can't guarantee that every app is blocked at all times. iOS controls Screen Time behaviour.
